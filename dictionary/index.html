What is in the set

The set covers the 500 beginner words used by Steno Start Pro. It includes 99 briefs and 401 rule-derived outlines. Eight words also have an optional two-stroke form. Every word was authored or generated for Steno Start; no GPL or commercial steno dictionary is included.

How it was built

Pronunciation comes from CMUdict. Theory, layout and brief patterns come from openly licensed steno references: Wikipedia's Stenotype article, selected Plover Wiki pages and the archived Art of Chording. The Steno Start rules and 500-word list are our own. The manifest records exactly which files were used, their licences, their hashes and the build command. The provenance file records the sources behind every entry.

What the compatibility figure means

The 500-word set matches 394 of 500 (78.8%) outlines exactly against a full external Plover dictionary used only as a black-box reference. That is a measure of agreement with one reference, not a claim that the dictionary is Plover, endorsed by Plover, or complete enough for professional work. It is a beginner teaching set.

How to use it

Download a file and inspect it, import dictionary.json into Steno Start Pro, or load it into your own tooling. The JSON is a flat map of word to outline, the common Plover dictionary shape. Multi-stroke entries use a slash between strokes. If you build something with it, keep the attribution and share your adaptation under the same licence.

Questions

Using the data.

For anything not covered here, get in touch.

Can I use this in my own app or project?

Yes, under CC BY-SA 4.0. Credit the Steno Start Open Dictionary and its sources, link to the licence, indicate any changes and share your adaptation under the same licence. The app's code and branding are not part of the data licence.

Is this the same dictionary that ships in Steno Start?

Yes. The 500-word set is the Steno Start Pro teaching dictionary. Steno Start Lite is a 135-word subset of it, and the 100 free sentences use only those Lite words.

Is it compatible with Plover?

It is a JSON word-to-outline map in the usual shape, so many Plover-style tools can read it. But it is a 500-word teaching set, not a full Plover dictionary, and agreement with Plover's outlines is 78.8% on this set. Check any outline before relying on it.

Why is there no full 6,000 or 100,000-word set?

A comprehensive English steno dictionary is not available under a permissive or share-alike licence that we can verify. The realistic large option is GPL data, and we do not want to mix that into a CC BY-SA set. Five hundred words is the honest, openly licensed beginner set we can publish and support.

How do I import it into Steno Start?

Unlock Pro, open the dictionaries screen and choose import. Paste the raw dictionary.json link from this page, or download the file and choose it from your device. The import stays local to your device.

Are the practice sentences included?

No. The dictionary download is the word set. The app also ships a separate pack of 3,000 Tatoeba sentences under CC BY 2.0 FR for use with imported dictionaries, with contributor attribution stored in the app's asset file.

Know someone learning steno?

Send them the dictionary page. It is free, openly licensed and does not need an account.
