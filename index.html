How it works

Three things to understand.
Then you are writing.

Steno is not a faster keyboard to type on. It is a different way to spell: several keys at once, one outline, one word. Steno Start teaches that shift slowly enough to stick.

  1. 01

    See the keyboard

    Twenty-two keys, two hands, four vowels. Steno Start labels every key and shows you which fingers belong where.

  2. 02

    Build a chord

    Tap the keys one at a time or press them together. A chord is written as one outline, and one outline is one word.

  3. 03

    Read it back

    The app shows the stroke in steno order, then asks you to write the next word in a real sentence.

Questions

The things people ask
before they start.

Still unsure? Send us a message and a real person will answer.

Do I need a steno machine?

No. Steno Start is a phone and tablet trainer: it shows the 22-key layout and lets you tap or touch chords on screen. To write at speed you will still need a steno keyboard or machine and software that runs it. Steno Start is a learning aid, not a system keyboard.

What exactly is steno?

Stenography is a chorded way of writing. Instead of typing one letter at a time, you press several keys together and the result is a word, a sound or a brief. Court reporters, captioners and live subtitlers use it to keep up with speech.

Is Steno Start a full steno course?

No. It is a guided introduction for someone who wants to understand the keyboard and try the skill before buying hardware or committing to a course. It teaches a 500-word beginner dictionary and gives you plenty of sentences to practise, but it does not promise professional speed.

Which devices does it run on?

Steno Start is built for Android phones and tablets, iPhone and iPad. The store listings are being prepared. The site will link to both as soon as they are live.

How much does Pro cost?

Pro is one in-app purchase of £3.99 in the UK. The store shows the exact price in your country before you buy. There is no subscription and no recurring charge.

Does it work offline?

Yes. Lessons, sentences, hints and progress are stored on your device. The app only uses the network when you ask it to import a dictionary from a URL.

Can I use my own Plover dictionary?

You can import a Plover-style JSON dictionary in Pro, from a URL or a local file. It stays on your device. Steno Start is independent and is not affiliated with Plover or Open Steno, and imported outlines are yours to check.

What happens to my progress if I uninstall?

Progress is stored locally, so uninstalling removes it unless your phone restores it from a backup. The app has a Reset local progress option if you want to start again deliberately.

Is any of this open source?

The 500-word teaching dictionary is published under CC BY-SA 4.0, with a manifest, provenance records and the sources used. You can download it, inspect it, reuse it and share it. The app itself is not open source.
